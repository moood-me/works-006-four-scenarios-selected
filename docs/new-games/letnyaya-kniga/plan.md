## Правила Павла (для всех пакетов)

  ключ, который движется.
- Затемнения — только игры (`bespoke.show/cut/fade`); у сцены нет ключа `fade`.
- Метки на людях — `'<id>#chest'`. Точки выборов и мини-игр — в средних 4:3 кадра, не внизу, не в углах.
- Люди ходят со своей скоростью; игра ждёт событий сцены, не секунд; немое до момента игры — не дольше ~8–10 с.
- Каждый файл — UTF-8 (байт не UTF-8 в коммите останавливает чтение деплоймента). Не писать файлы PowerShell'овским
  `Set-Content`/`Out-File` без `-Encoding utf8`; перед коммитом — `iconv -f UTF-8 -t UTF-8 <файл> >/dev/null` по

- Мультиязычность: тексты литералами через `tr`/`say`, исходник английский (тон английской Янссон), русский рядом —
  реплики сценария как есть; `@moood/check` чистый.
- Только правильные пути: пробел движка или языка — описать (что, где, как повторить) и вернуться к координатору; не
  обходить и не пересылать другим агентам.
