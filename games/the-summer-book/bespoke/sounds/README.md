# The beds' recordings

Real recordings from Freesound, CC0 licence (no conditions): a piece of ~45 s cut from each, looped (the last 2.5 s mixed
into the start), the loudness brought to −24 dBFS RMS, MP3 96 kbit/s — the ones Pavel chose for the games on
2026-10-16 (rpg docs/history/2026-10-16-game-sounds.md), taken as they are; `sound.js` fits each to its bed's loudness.
